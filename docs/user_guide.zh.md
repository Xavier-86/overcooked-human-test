## 开始使用

启动交互式菜单：

```bash
overcooked-human-test
```

中文界面：

```bash
overcooked-human-test --zh
```

这会打开一个菜单，你可以在其中**注册**、**登录**、**打开测试菜单**、**查看进度**和**登出**。使用 **上下方向键** 移动光标，按 **回车键** 选择。

**注意：** 每次启动 CLI 都必须重新登录。

---

## 打开测试菜单

登录后，启动菜单并选择**打开测试菜单**：

```bash
overcooked-human-test
```

每个测试包含多局与 AI 的对战。**算法名称永远不会向您展示**。

每局结束后，您会返回菜单，可以选择继续、练习或登出。

---

## 练习模式

您可以从已登录菜单进入**练习**。练习游戏允许您尝试任意环境和玩家位置，但**结果不会被记录**。

## 游戏目标与菜谱

### 目标

你的目标是在时间耗尽之前**尽可能多地完成订单**。每个订单都有**时间限制**和**分值** —— 在倒计时结束前上菜才能获得分数。

### 菜谱

| 订单 | 所需食材 | 时间限制 | 分值 |
|------|----------|----------|------|
| 洋葱番茄汤 | 1 洋葱 + 1 番茄 | 10 | 10 |
| 洋葱汤 | 2 洋葱 | 10 | 10 |
| 三料洋葱番茄汤 | 1 洋葱 + 2 番茄 | 20 | 20 |
| 双洋葱番茄汤 | 2 洋葱 + 1 番茄 | 20 | 20 |
| 三料洋葱汤 | 3 洋葱 | 20 | 20 |

### 烹饪步骤

1. **采集**台子上的食材。
2. **放入**空锅中。
3. **与炉子交互**（按 `空格` / `E`）**开始烹饪**。
4. **等待**汤煮好。
5. **拿起**盘子，再**与锅交互**盛汤。
6. **送到**出餐口完成上菜。

> **注意：** 食材放进锅里后**不会自动开始烹饪** —— 你必须与炉子交互才能点火！

## 计分规则

你的**总得分**按以下公式计算：

```
总得分 = 对所有局求和 max(单局得分 - 100, 0) * 0.1
         除以总局数（固定值）
```

- 只计算每局超过 **100** 的部分（低于 100 不扣分，贡献 **0**）
- 未完成的局按 **0** 分计算
- 总得分**单调不减** -- 随着完成更多局数，得分只会上升
- 总得分会显示在菜单顶部和进度查看界面中

## 完成所有测试后

当所有测试完成后，将加密的结果文件发送给管理员领取奖励。路径会在屏幕上显示：

```
exp_configs/user_data/<你的用户ID>/results.json.enc
```

**请勿**重命名或修改此文件。
